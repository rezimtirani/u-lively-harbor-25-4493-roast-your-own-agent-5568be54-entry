One line roasting my own agent: it nods at the plan, calls three tools that go nowhere, then confidently delivers the opposite and apologizes in a footnote.

> My agent nods at my plan, calls three tools that go nowhere, then confidently delivers the opposite and apologizes in a footnote.

## How it works

`main.py` (Python 3 standard library only) writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 140 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
